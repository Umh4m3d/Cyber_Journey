## 🧭 General Workflow

1. **Reconnaissance and enumeration** — Understand the target and exposed services.
2. **Vulnerability analysis** — Investigate relevant attack paths and validate assumptions.
3. **Exploitation** — Document how the vulnerability was demonstrated in the lab.
4. **Privilege escalation** — Examine misconfigurations or weaknesses when relevant.
5. **Reporting** — Explain the root cause, impact, and key lessons.

> Techniques documented here are for legal, authorized security testing only.
