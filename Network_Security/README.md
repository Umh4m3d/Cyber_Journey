# 🌐 Network Security

Hands-on **computer networking and security fundamentals**, with Cisco Packet Tracer exercises, configuration labs, troubleshooting practice, and supporting reports.

## 📁 Topics

| Area | Labs and notes |
|---|---|
| [Layer 2 — Switching](./Layer2/) | STP, VLANs, and switching troubleshooting |
| [Layer 3 — Routing](./Layer3/) | Static/default routes, RIP, OSPF, DHCP, NAT, and troubleshooting |

## 📄 File Formats

- **`.pkt` / `.pka`** — Cisco Packet Tracer lab or activity files.
- **`.pdf`** — Lab reports, explanations, and troubleshooting notes.

Some resources are available in **English and French**. Packet Tracer is needed to open `.pkt` and `.pka` files.
